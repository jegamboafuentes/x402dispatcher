INFORMATION 
┌─ ABOUT ────────────────────────────────────────────┐
│ x402dispatcher is a solo-operator Bazaar aggregator│
│ for AI agents. It discovers paywalled APIs from the│
│ Coinbase x402 catalog, wraps them as MCP tools,    │
│ settles USDC micropayments on Base, and keeps a    │
│ cashflow ledger so you can monitor the business.   │
│                                                    │
│ Agents pay inbound (→ Merchant). Treasury pays     │
│ upstream sellers. Markup stays with the operator.  │
│ No card custody — settlements are on-chain USDC.   │
└────────────────────────────────────────────────────┘

┌─ GLOSSARY ─────────────────────────────────────────┐
│ PnL              Profit & loss summary from the     │
│                  cashflow ledger.                  │
│                                                    │
│ revenue (in)     Money received from calling       │
│                  agents → Merchant (inbound x402). │
│                                                    │
│ cogs (out)       Cost of goods sold: Treasury →    │
│                  upstream API seller payments.     │
│                                                    │
│ markup           Internal Treasury → Merchant      │
│                  spread transfer (float model).    │
│                                                    │
│ gross profit     revenue − cogs (true margin when  │
│                  inbound paywall is on).           │
│                                                    │
│ Treasury         Burner float wallet that pays     │
│                  upstream APIs (needs USDC + ETH). │
│                                                    │
│ Merchant         Operator wallet that receives     │
│                  inbound agent payments + markup.  │
│                                                    │
│ settlement       One ledger row: in / out / markup │
│                  with optional Basescan tx link.   │
│                                                    │
│ inbound paywall  When ON, agents must pay before   │
│                  paid MCP tools run.               │
│                                                    │
│ Basescan         Block explorer for Base. Wallet   │
│                  and tx links open there.          │
└────────────────────────────────────────────────────┘
